# Verified implementation status

Last verified: 2026-08-09.

This is the canonical implementation audit and requirements traceability record. The product specification remains authoritative for intended scope; this file records only observed code, tests and local evidence.

Status terms:

- **Production slice** — the real Worker path is authorised, validated and backed by D1/R2/Queue/provider boundaries. This does not mean a production deployment was verified.
- **Production foundation** — shared runtime/infrastructure used by production slices.
- **Partial production slice** — meaningful server-backed behavior exists, but a required workflow boundary is missing.
- **Frontend foundation** — real interface without a complete owning production service.
- **Schema only** — tables/types exist without an executable product workflow.
- **Demonstration only** — explicitly environment-gated seed or simulation, never a production fallback.
- **Not implemented** — no credible executable path was found.

## Verification evidence

The reproducible validation gates are:

```bash
npm run check:core
npm run check
```

The latest integrated checks in this workspace include:

- `npm run typecheck` passed, including Wrangler bindings, React Router route generation and the TypeScript project build.
- `npm test` passed 305 focused cases across 36 test files: 57 deterministic cases in the Node project and 248 Cloudflare integration cases covering auth, events, submissions, evaluation, speakers, tasks, files, resources, schedule, public programme, communications, calendars, readiness, API keys/CORS and realtime isolation.
- `npm run build` and `npm run openapi:check` passed; the latter verifies eight documented route paths, 75 internal references and exact YAML/JSON synchronization.
- Migration validation for 72 application tables, 66 named indexes, foreign keys, cross-tenant constraints, file-release invariants, two append-only audit triggers and automatic schedule-policy provisioning.
- All 68 Playwright checks passed against the production-built local Worker: Event Setup, submission, explicit unknown-record failure, unsubscribe, realtime, schedule/programme and speaker portal behavior; keyboard/focus, naming/error, mobile reviewer controls, contained wide-grid navigation, zoom-equivalent, mobile-chrome and landmark accessibility coverage; and the visual suite below.
- Forty-two visual snapshots: 21 core production/demo surfaces at desktop and mobile widths, each with horizontal-overflow assertions.

Passing isolated provider tests prove request boundaries and failure behavior, not live Resend/Google/Microsoft delivery. Passing local Worker tests do not prove a deployed Cloudflare environment.
