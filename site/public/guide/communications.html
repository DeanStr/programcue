Communications and calendars

Send programme email from a published template. Optionally connect Google or Microsoft so session invitations stay in step with the published schedule.

Set up the sender

Email goes out only from a verified sender. If that sender is missing or not yet verified, send stops and says why. Program Cue will not switch to another email service to make the button look successful.

Templates

  1. Edit a draft template in Communications.
  2. Preview it with sample merge data.
  3. Publish a new version when the copy is ready.

Reminders and one-off sends use that published version. Later edits do not change mail that already went out.

Compose, preview and send

  1. Write the draft in the composer.
  2. Preview the current content, audience and sender together.
  3. Confirm the recipients before the message leaves the draft.
  4. Send now, or schedule a send. A scheduled send still needs the same sender and template.

Bounces and other delivery results stay on that send. If a batch is still running, open Operations to see the recorded progress.

Reminders

Each automatic reminder has its own trigger. An overdue-task reminder does not share state with another reminder. Turn a trigger off from Communications when the event’s timing changes.

Calendar invitations

You and speakers can connect Google Calendar or Microsoft 365 so Program Cue can create, update and cancel the session invitations it manages. Google access is limited to those invitations. It does not browse the rest of the calendar. Either connection can be disconnected later.

When you publish a new schedule, those invitations are updated or cancelled to match. Email can still carry a calendar attachment if nobody has connected a calendar.

Read how Program Cue handles Google user data before you connect Google.

Unsubscribe

A recipient can leave programme email from the unsubscribe link. Later sends respect that. It does not remove them from the event or hide the public programme.
