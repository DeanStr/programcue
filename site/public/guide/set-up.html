Set up an event

Owners and administrators define the event before intake opens: dates, rooms, tracks, people, branding and the public event website.

Create or clone an event

You can create or clone an event only after you already belong to an organisation as an owner or administrator. Signing up does not create that organisation. If you do not have one yet, see Accounts and access.

  1. Open New event from the event chooser or the administration menu.
  2. Choose where this event’s records will live: Program Cue, or an Airtable base that you want to treat as the source of truth.
  3. Confirm the choice. Nothing is created until you do.

Clone event copies a previous Program Cue event. Check the preview, then confirm. The public web address uses the event slug, and that slug must be unique.

If creation stops halfway, open Recover event repository. Program Cue will not finish a stuck event in the background and call it done.

Event settings

Open Event settings and set the name, dates, timezone, venue, city and public slug. Add the venue address and a map link if attendees should see them on the event website. Add rooms, tracks, session formats and durations before you build the schedule.

  • You cannot remove a room or track that still has sessions. Move those sessions first.
  • Track and Format questions on the application form follow these Event settings choices. Change them here, not in the form builder. See Applications.
  • If someone else saved while you were editing, you will be asked to resolve the clash. The later save does not overwrite the earlier one in silence.

Invite administrators

Invite administrators from Event settings. You can invite them to this event, or — if you are an owner — to every event in the organisation. That dialog creates administrators, not owners. If email is not set up, the invite stops and says so. It will not look as if it was sent.

Removing an administrator depends on their scope. An event administrator loses this event only. An organisation administrator loses every event in the organisation. Their account remains.

Branding

Open Branding to set the event mark, accent colour and the logo speakers see. Program Cue prepares uploaded images before they are used. Publishing branding asks you to confirm. Unpublished branding stays in the workspace.

Event website

Open Event website to write the public homepage and the optional About, FAQ, Venue, Code of conduct and Sponsors pages. The homepage has fixed sections you can hide or reorder: introduction, featured speakers, featured sessions, venue, FAQ and programme statistics.

You can publish the site before the programme so people can read the call for speakers. Featured speakers, featured sessions, Programme statistics and recordings cannot appear until a programme is published. Hide Programme statistics if it is still on. A featured speaker must be confirmed on a published public session. Preview desktop and mobile, then publish. Visitors see the published version, not your draft.

Command Centre

Home in the administration menu opens Command Centre. Until setup is complete it shows Programme setup in four phases:

  1. Set up — describe the event and publish an application form.
  2. Collect and decide — configure review.
  3. Prepare speakers — create participant tasks and verify the sender.
  4. Publish and verify — publish a conflict-free programme.

That setup guide disappears when every step in those four phases is complete. Command Centre still shows overall readiness, overdue tasks, clashes that block publication, and similar work. Use it when you want the next job, not a tour of every screen.
