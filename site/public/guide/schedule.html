Schedule and publication

Programme is the calendar. Programme publishing is the public snapshot. Nothing unpublished appears on the attendee programme, gallery, calendar feed or public API.

Place sessions

  1. Open Programme. Switch between list, day and week as you need.
  2. Drag or resize a session, or use the keyboard to make the same move. You can unassign a session and undo a change.
  3. Add breaks and held rooms as real items, not leftover gaps.

Formats, durations, tracks and rooms come from Event settings. Bulk changes show a preview first. After they apply, you can reverse them.

Fix clashes before you publish

Program Cue flags speaker, room and related clashes as you work. Clashes that block publication are checked again when you publish. You cannot publish while one of those remains. Command Centre and the schedule filter list the sessions that still collide.

Session content

Open Session content & files to edit titles, abstracts, format, duration, track, visibility and session resources. Speakers on the session are listed read-only. Files live in the file library. Approving copy records who approved it. Restoring an earlier version is a deliberate action. Public pages use the approved, published version, not the live draft.

Unfinished notes save as you go. A restored draft is labelled. If two tabs both have unsaved edits, you will be asked to resolve the clash.

Publish the programme

  1. Fix every clash that blocks publication.
  2. Confirm publish. Program Cue stores that version and updates the public programme, gallery, calendar feed and published API to match it exactly.
  3. Later edits stay in the workspace until you publish again. Session invitations that Program Cue manages are updated or cancelled to match.

What attendees see

The public programme is app.programcue.com/public/programme/ plus the event slug. From there people can open speakers, the agenda, a personal itinerary and the speaker gallery. They do not need an account. The itinerary only holds published sessions.

Website embeds

Open Programme publishing, then Publish & embed, to create a managed embed for a partner site. The embed uses the published programme snapshot. If the event is not published, the embed does not look live.
