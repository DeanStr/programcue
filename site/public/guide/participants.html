Speak or submit

This is for speakers and submitters. One workspace holds your applications, sessions, tasks, files, resources and profile.

Get in

Use the link the event team sent you:

  • A published application link, to propose a session.
  • A co-speaker claim link, if someone named you on a form.
  • An invitation, if an organiser added you as a speaker. Accept that portal invitation before you expect to see the workspace. Until then the membership stays pending. Accepting the invitation is not the same as confirming a session.

Then sign in at app.programcue.com/sign-in. If you see “no workspace access”, the link is missing or was sent to a different email.

Overview

Overview is the home of the participant workspace. It shows what is still due. The same menu has Applications, My sessions, Tasks, Files, Resources and Profile.

Start or finish an application

  1. Open Applications, or open the published apply link.
  2. You can start without signing in. Sign in if you want to come back from another device.
  3. The form saves as you type. It shows Saving, Saved, Offline or Retry required. Refreshing brings back the last saved draft.
  4. Name co-speakers if the form asks. They get their own claim link.
  5. You can pull in a public Sessionize speaker profile. That reads one public page. It is not a Sessionize login.
  6. Submit when the form is complete.

Confirm your sessions

Open My sessions. When a session is ready, confirm your participation. The organisers see that confirmation. They cannot publish you on the public programme until you confirm, or until they record that they confirmed you outside Program Cue. Unpublished schedule details stay hidden until they publish the programme.

Complete tasks

Open Tasks. A task might ask you to acknowledge a page, answer a short form, upload a file, visit a link or finish a checklist. Some tasks stay locked until an earlier one is done. Attach evidence when the task asks for it.

Upload files

Open Files to add a headshot, slides or supporting documents. Uploads are private. They stay held until the required file check finishes. If that check fails or is unclear, the file is not released. A large upload can resume if the connection drops.

Read resources

Open Resources for pages the organisers published for you. Some pages have an acknowledgement task. Read the published page, then complete that task so the organisers can see you have done it.

Save and publish your profile

  1. Open Profile and fill in the identity the programme will use.
  2. Travel and logistics notes stay private to you and the organisers. They never appear on the public programme.
  3. Tick “Publish this profile when saved” if the public programme should use it, then choose Save profile.

Organisers still approve what appears on the published programme. Saving a draft does not put you on the public site by itself.

Connect a calendar

On Overview you can connect Google Calendar or Microsoft 365 so Program Cue can send session invitations from your own calendar. This is optional. You can disconnect it later. Email calendar attachments still work without a connection.

If you run the event, use Speakers, tasks and resources instead of this page.
