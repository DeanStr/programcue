Operations, API and integrations

Check long-running jobs, import or export CSV, and connect Airtable, Accelevents or the API. If a connection is missing, the workspace says so.

Operations

Open Operations to watch imports, exports, sends and similar batches. Open a job to see each item, then retry, cancel or skip one. The status you see is the recorded result, not a spinner that implies success.

CSV import and export

  1. Export a working copy, or start an import of speakers, sessions or results.
  2. Check the preview of rows that will be created or changed.
  3. Confirm before anything is written.

A bad row is marked invalid in the preview. You cannot confirm the import until every row is valid. The good rows do not land on their own.

Search and saved views

Use Search records and run commands to find records in the current event or run a command. Saved views remember a filter on Applications and similar lists. Search across the whole organisation is for owners.

API and webhooks

Open API & webhooks to create an event key or register a webhook. The reference is app.programcue.com/api/docs. Public paths return published data. Administration and participant paths need the matching key or a signed-in session.

Retry a command with the same Idempotency-Key and Program Cue will not apply it twice. A new key starts a new command. A webhook is recorded before it is sent. A failed delivery stays failed until you retry it.

Integrations

  • Airtable can be the source of truth for an event if you choose that when you create the event, or configure it later. Preview the move and confirm it. If Airtable is not connected, those actions stop and say so.
  • Accelevents can preview, dry-run, export, retry and produce a reconciliation report. A dry run does not write to Accelevents. A live export needs credentials.
  • Google and Microsoft cover sign-in and optional calendars. See Accounts and access and Communications and calendars.
  • Resend sends production email once a verified sender is in place.

If a credential, permission or remote record is missing, the workspace says so. It does not invent a successful result.

Event assistant

The event assistant can suggest a small change, such as a task update, for you to approve. It cannot bypass your role, and it will not apply a consequential change on its own. If AI is not set up, the assistant is unavailable. It is not simulated.

For help with these connections, write to support@programcue.com.
