Product guide

How to use Program Cue at app.programcue.com. Start from the invitation or application link you were sent. Creating an account does not give you an event on its own.

Last updated: 17 August 2026.

If you were asked to take part

Open the email or link from the event team, then sign in. Use the short guide that matches what you were asked to do.

  • Evaluators

    Review assigned proposals

    Accept the invitation, open the Review workbench, score what you were assigned and recuse if you have a conflict.

  • Speakers and submitters

    Speak or submit

    Start or finish an application, confirm your sessions, complete tasks and publish your profile.

If you need an event workspace

Signing up only creates your login. It does not create an organisation or an event. You get into a workspace when an organiser invites you, or when you open a published application link.

If you run a conference and need a Program Cue workspace, write to support@programcue.com. After you are an owner or administrator of an organisation, you can create or clone further events yourself. See Accounts and access.

If you run the event

Work through the programme in this order. Command Centre on the Home item of the administration menu shows what is still blocking each stage.

  • Everyone

    Accounts and access

    Sign in, accept an invitation, choose an event and see what each role can do.

  • Organisers

    Set up an event

    Create or clone an event, add rooms and tracks, invite administrators and publish branding.

  • Organisers

    Applications

    Build the call for speakers, publish the form and work the queue of applications.

  • Organisers and chairs

    Review and selection

    Plan rounds, invite evaluators, assign work and turn accepted proposals into sessions.

  • Organisers

    Speakers, tasks and resources

    Onboard accepted speakers, track tasks and publish pages for the participant workspace.

  • Organisers

    Schedule and publication

    Place sessions, fix clashes and publish the public programme.

  • Organisers

    Communications and calendars

    Send email from a checked template and keep session invitations up to date.

  • Organisers

    Operations, API and integrations

    Check long-running jobs, import or export CSV and connect Airtable, Accelevents or the API.

If something fails

Program Cue tells you when email is not set up, a connection is missing or a schedule clash is still blocking publication. The action stops and names the problem. It does not pretend the work succeeded. Public programme pages only show what you have published.
