One operational thread

Keep the programme moving, even as the details change.

Conference programmes rarely fail because a team cannot make a decision. They become difficult when context is split between forms, spreadsheets, inboxes and calendars. Program Cue keeps each decision attached to the work it affects.

  1. 01

    Move from proposal to decision

    Configure the call, assign structured reviews and preserve the decision trail that turns an accepted proposal into a session.

  2. 02

    Act on readiness, not guesswork

    See the speaker, task and communication blockers that need action before they become programme-day problems.

  3. 03

    Publish from a checked schedule

    Build across rooms and tracks, resolve blocking conflicts, then publish an exact programme snapshot for attendees and partners.

Connected capabilities

One system from call to published programme.

Every capability shares the same event context, so programme teams spend less time reconciling records and more time resolving the work that matters.

  • Collect

    Submissions

    Configure submission forms, retain immutable submitted versions and keep proposal details, people and attachments together.

  • Decide

    Reviewing

    Run assignment-based review rounds with explicit criteria, conflicts, moderation and recorded outcomes.

  • Prepare

    Speakers

    Track confirmations, profiles, session materials and outstanding tasks without separating speakers from their sessions.

  • Place

    Programme scheduling

    Plan across days, rooms and tracks with keyboard alternatives and blocking conflict checks at publication.

  • Coordinate

    Communications

    Preview consequential sends, reuse approved templates and retain honest per-recipient progress and delivery results.

  • Reconcile

    Calendar invitations

    Optionally connect Google or Microsoft calendars so managed invitations stay aligned when sessions change or are cancelled.

Operational confidence

Designed for consequential programme work.

Program Cue makes access, publication and external work explicit. It does not hide missing credentials, provider failures or schedule blockers behind simulated success.

  • Permission-aware by default Private work is isolated by organisation, event and role.
  • Consequences stay visible Material changes use preview, confirmation and honest progress.
  • Publication is deliberate Public programme endpoints expose published snapshots only.
  • Private files stay private Uploads remain quarantined until their required checks clear.

Optional connection

Google integration, with a bounded purpose.

Google Sign-In can be used to create or access a Program Cue account. Users may also optionally connect Google Calendar so Program Cue can create, update, cancel and reconcile session invitations managed through Program Cue.

Program Cue requests these Google permissions:

  • Sign-in: openid, email and profile, used only to authenticate you and to create or match your Program Cue account.
  • Optional calendar connection: https://www.googleapis.com/auth/calendar.events.owned, used only for Program Cue-managed invitations on your primary calendar.

The calendar connection is optional and can be disconnected at any time. Program Cue does not provide general calendar browsing and does not use Google Calendar data for advertising.
